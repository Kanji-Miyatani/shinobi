# それ、何時間で払える？

都道府県と買いたいものを選ぶと、「それを払うのに何時間働く必要があるか」を表示する静的Webアプリです。金額ではなく労働時間で比べることで、地域ごとの値札の重さを見えるようにします。

要件定義書「それ、何時間労働？」版数0.1 をもとに作っています。2026年9月24日の要件変更で、iPhone の商品プリセットをやめ、県ごとに価格が違う品目（家賃・物価）を扱う方針にしました。サイト名は「〇〇、何時間で払える？」の形にする予定で、〇〇が決まるまでは「それ、何時間で払える？」としています。

## できること

- 47都道府県から県を選ぶ（プルダウン、またはタイル型の日本地図をタップ）
- 収入の基準：最低賃金（平均賃金・中央値は準備中）
- 支出：任意の金額。県ごとに価格が違う品目（平均家賃、物価の品目）はデータ取り込み待ち
- 結果：「○時間○分」と「8時間勤務で○日ぶん」、全国加重平均との横棒グラフ
- 最低賃金の新旧切替：発効日前の県は改定前の額と改定後の額を両方表示
- 立体の日本地図（Three.js）：県境の形を立ち上げ、必要時間を高さと色で表示。ドラッグで向きを変え、タップで県を選ぶ。WebGLが使えない環境や「マス目」表示では、数字つきのタイル型地図を表示
- 2県比較の棒グラフ、47都道府県ランキング（同じ時給は同順位）
- シェアカード：横長（1200×630）／正方形（1080×1080）、地図か比較棒グラフを選べる。端末の共有機能、非対応なら画像保存
- ホーム画面に追加できる（Web App Manifest と Service Worker）

入力や選択は端末の中だけで計算し、送信・保存はしません。

## 動かし方

ビルドは不要です。`fetch` でデータを読むため、ファイルを直接開かずにローカルサーバーで表示してください。

```sh
npm start        # http://localhost:8080
npm test         # 計算ロジックとデータの検証
```

GitHub Pages など、静的ファイルを置けるホスティングならそのまま公開できます。

## データ

| 項目 | 出典 | 状態 |
| --- | --- | --- |
| 最低賃金 | 厚生労働省「全ての都道府県で地域別最低賃金の改定額が答申されました」ほか各都道府県労働局の発表 | 令和8年度答申額と令和7年度額、発効予定日。2026年9月24日取得 |
| 県境 | 国土交通省 国土数値情報「行政区域データ 2025年版」（CC BY 4.0）。[japan-choropleth](https://github.com/kyodo-official/japan-choropleth)（共同通信社）の都道府県ポリゴンを mapshaper で簡略化し、面積100km²未満の島を除いたもの | 表示の都合上、沖縄県は日本海側の枠内に移設 |
| 平均家賃 | 住宅・土地統計調査（令和5年）借家の1か月当たり家賃 | 未収録（e-Stat から取り込み予定） |
| 物価の品目 | 小売物価統計調査（水道料・灯油など） | 未収録（e-Stat から取り込み予定） |

最低賃金の検証メモ：

- 47都道府県の引上げ額の内訳（54円〜65円）は、厚生労働省の答申まとめと一致することを確認しています。
- 群馬・石川・福井の発効日は労働局のページで直接確認できず、民間の集計サイトと報道の記載に基づいています。
- 高知・宮崎・鹿児島の発効日は答申段階の予定日です。
- 公示で確定額・発効日が決まったら `data/data.json` を更新し、`sw.js` の `VERSION` を上げてください。

## 更新の予定

- 3月：賃金構造基本統計調査（平均賃金）
- 6月：消費者物価地域差指数（物価）
- 10〜12月：最低賃金の発効にあわせて確定額へ

データを更新したら `npm test` を実行し、計算結果を公表値から手計算した値と照合してください。

## デザインの方針

- シグネチャーはタイムカード。結果は打刻機で印字したようなドット書体で表示し、条件を変えるたびに打刻の動きが入ります。
- 配色：墨 `#1c1633`、ひまわり `#ffd23f`、トマト `#ff4f2e`、ミント `#2ec4b6`、ピンク `#ff8ac5`、空色 `#6ec1ff`。地図は必要時間が長いほど濃いトマト色の1色濃淡です。
- 書体：見出しは Dela Gothic One、本文は Zen Kaku Gothic New、数字は DotGothic16。
- 立体地図はトゥーン調の陰影と墨色のずらし影で、ページのコミック調に合わせています。
- セクションの境目は、タイムカードのミシン目と斜めのカットの2種類です。

## 注意

- 時給は額面（税・社会保険料の控除前）です。
- 立体地図の高さは47都道府県の中での相対値です（最も短い県を低い基準にしている）。正確な値は数字つきのマス目表示とランキングで確認できます。
